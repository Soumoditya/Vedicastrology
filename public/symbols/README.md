# Your symbol images

The site draws Ganesha, Om and the Swastika as gold line-art in code, so it
needs no image files to look right. This folder is only for using your own
artwork instead.

To swap any one in:

1. Save the image here with one of these names:
   - `ganesha.png`
   - `om.png`
   - `swastika.png`
2. Pass its path to the ornament where it is used, for example:
   `<Ganesha src="/symbols/ganesha.png" />`

Transparent PNG or SVG works best. A plain white background will show as a
white box on the dark theme, so trim it to the figure first.
